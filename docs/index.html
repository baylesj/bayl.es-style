bayl.es style

A code editor's color theme, translated to the web. Color works like syntax highlighting, words are set in a grotesk, and machine facts in your editor's mono. It's one family, with a small context clue per site. This page is built with the stylesheet it describes; switch the site and theme above to see each signature.

01principles

02signatures

One hue per site, fading into a neighbor. It shows up on the strip at the top, the dot after the wordmark, the prompt path, panels and the primary button.

03color roles

Each hue is a role, the same on every site. The ratio under each swatch is measured live against the page in the current theme. Text colors need 4.5:1; fill-only colors need 3:1.

06contrast

Every text color meets WCAG AA (4.5:1) on the page and on every tinted panel, in both themes; non-text marks (field borders, focus rings, dots) meet 3:1.

Each hue comes in two strengths: the role color is safe for text, and *-bright / --sig-fill are for fills only. Unavailable items turn grey, never faded. When adding a color, check it on the page and on the darkest panel tint it can sit on. The ratios in section 03 are live.

07favicons

Server sites: an "e." monogram on a tile in the site's signature color. jordan.bayl.es: the Chasma Sound logo, white on black (in that repo).

08never

  • cream or beige grounds
  • serif type, except the name on jordan.bayl.es
  • bordered white cards as the default container
  • drop shadows
  • gradients other than the signature strip
  • pill buttons
  • uppercase letter-spaced labels
  • emoji
  • color used only to decorate
  • faded text for disabled states
  • Inter, Roboto, Arial, Geist
